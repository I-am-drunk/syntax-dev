UI & Example Storybook

Interactive @syntax/ui controls, learning primitives, and runnable course and tool examples.

Nightly source: f92dc807 (v0.3.0-nightly.20261128.19)

Syntax exposes a live @syntax/ui module to installed native extensions so courses and tools stay visually cohesive and pick up host UI improvements without rebuilding.

  • Open live Storybook: https://syntax-platform.github.io/syntax-dev/storybook/
  • Run locally: npm run storybook
  • Build static bundle: npm run build-storybook

Included Stories

  • Controls (Controls.stories.tsx): Button, Card, Badge, ProgressBar, Segmented, Toggle, and Sema.
  • Starter Course Lesson (CourseExample.stories.tsx): Interactive 3-step lesson using LessonShell, LessonHeader, ChoiceGroup, WorkedSteps, CheckBar, CompletionCard, and a bundled SVG diagram.
  • Standalone Tool (ToolExample.stories.tsx): Autosaved scratchpad built with @syntax/ui.
